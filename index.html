System Architecture Case Study

ForgeCAD: OCR-Based CAD Processing Platform

Industrial Engineering Drawing Ingestion, Coordinate HUD & Manufacturing Kanban

Core Engineering Architecture

ForgeCAD addresses the gap between technical engineering drawings (PDFs, DXF, DWG, raster blueprints) and digital manufacturing execution. The system features a 6-phase canvas preprocessing routine:

  • Phase 1-3 (Image Denoising): High-pass adaptive contrast enhancement, thresholding, and morphological filtering to isolate text and dimension labels from mechanical geometry lines.
  • Phase 4-5 (Optical Extraction): Optical Character Recognition engine parses numerical dimensions, diameter symbols (Ø), and tolerance bounds (±0.05mm).
  • Phase 6 (HUD Coordinate Mapping): Extracted bounding boxes are normalized against the drawing aspect ratio and mapped to the interactive blueprint viewport with HUD coordinate reticles.

Manufacturing Tracking & BOM Integration

Extracted specifications link directly to a drag-and-drop manufacturing tracking Kanban board supporting state progression across PENDING → PROCESSING → MANUFACTURING → QC → ASSEMBLY → COMPLETED. Each component updates active floor yield metrics and circular completion rings in real time.

AURAVISION: Offline AI Human Activity Recognition

Real-time Vision Sequence Validator for Standard Operating Procedures (SOPs)

Hackathon Problem & Mission

Built for the Smart India Hackathon (SIH), AURAVISION addresses the need for automated safety and procedure enforcement in laboratory environments where network connectivity is restricted and real-time execution safety is vital.

Deterministic Sequence Validation Engine

Rather than relying solely on black-box probabilistic models, AURAVISION couples deep learning keypoint and object detection with a deterministic finite-state sequence validator:

  • State Timeline: Verifies sequential milestones (PICK_TOOL → OPEN_CONTAINER → TAKE_SAMPLE → PLACE_SAMPLE → CLOSE_CONTAINER).
  • Violation Interceptor: Instantly detects and categorizes anomalies: STEP_SKIPPED, OUT_OF_SEQUENCE, MISSING_OBJECT, and LOW_CONFIDENCE.
  • Hands-Free Alerts: Built-in Text-to-Speech (TTS) synthesis and Web Audio API synthesized frequencies alert operators immediately without requiring them to glance at a screen.

Offline Reliability & Testing

Designed for 100% offline edge deployment. Verified with automated Pytest unit and integration test suites covering camera pipelines, session life-cycles, and sequence validation scenarios.
